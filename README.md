# Super Factory Manager Scripts

This is a collection of scripts for Super Factory Manager (SFM) that I have used for my modded Minecraft sessions (currently just All The Mods 10 TTS). Mostly just automating resource generation, crafting, etc. from various mods. I also included some screenshots, as well as the places where I got the initial scripts from.

If you use VSCode i would recommend installing [this extension](https://marketplace.visualstudio.com/items?itemName=TeamDman.super-factory-manager-language) to get language support for .sfm files.
